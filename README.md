## Project Ownership and Usage

Website: https://fardocosmetics.com

Fardo Cosmetics is a custom e-commerce website developed as a freelance project for a client.

The project was created to support the client's online business operations, including product management, customer shopping, order processing, and payment integration.

This repository serves as technical documentation for the project and its maintenance.

**Ownership and usage rights:** The project is client work. Its source code, design, branding, and related assets are not presented as an open-source project. Any reuse, redistribution, modification, or commercial use is subject to the agreement between the developer and the client.

**Contributions:** This is a private client project. External contributions are not currently being solicited.
